# CreatorScope V1.4 课堂演示指南

核对日期：2026-11-21（Asia/Shanghai）  
项目：`K:\work\CreatorScope`

## 离线演示

在 Windows PowerShell 中进入项目目录并运行：

```powershell
cd K:\work\CreatorScope
.\run.ps1 -Mode Demo
```

默认访问 `http://127.0.0.1:8765`。如果实时服务已占用端口，可在新 PowerShell 窗口指定其他本地端口：

```powershell
$env:CREATORSCOPE_PORT = '8766'
.\run.ps1 -Mode Demo
```

演示模式使用 `data/demo/creatorscope_demo.sqlite3` 中的本地真实历史数据副本；不启动平台浏览器、不需要平台登录、Agent、MCP 或模型 API Key。页面、ECharts、统计、词云和导出均从本地应用与副本读取。演示模式拦截写请求；该数据副本与正式实时数据库分开。

本次已验证的演示库包含 17 个 creator 实体、16 条 notes、92 条 records、12 个历史批次、33 条评论快照。它没有纳入当前正式数据库本轮新增的部分 V1.4 采集记录。演示时应将其称为“真实历史数据离线演示”，不要说成刚刚完成的 V1.4 实时采集结果。

## 推荐演示顺序

1. **数据看板**：展示实体数、来源占比、字段覆盖和最近更新时间。
2. **统计分析**：展示粉丝、报价、领域、画像、互动散点和正文词频；同时说明当前真实历史样本量及字段缺失。
3. **笔记与样本记录**：按批次或来源筛选，查看来源、时间和原始采集记录。
4. **评论分析**：查看真实历史评论词频及分布；本演示库 33 条评论快照，不代表全量评论。
5. **导出**：演示 JSON、CSV 和统计 JSON。导出读取当前筛选或全部本地历史副本。

本地看板截图：[V1.4 离线看板](../output/playwright/v14-demo-dashboard-20261121.png)。

## 当前分析样本边界

- 正文词频以 11 篇真实历史笔记生成；其他文字类型需在页面选择后核实对应有效样本量。
- 受众分析当前有 7 条历史画像快照，按来源与页面统计周期分组。
- 粉丝与报价没有足够共同字段，当前不能作联合关系结论。
- 当前历史样本没有可用于创作者趋势的同创作者、同来源、同指标和同统计周期重复快照。
- 样本不足时保留页面提示，不使用虚构数据补齐。

## 实时采集模式

实时采集需使用默认模式：

```powershell
cd K:\work\CreatorScope
.\run.ps1
```

访问本地应用后，在可见浏览器中正常登录蒲公英。按课程任务选择小样本，查看进度和字段质量报告。遇到手机号提示时只使用页面正常关闭控件；遇到验证码、安全验证或权限拒绝时，遵循平台提示，任务按断点暂停，待正常处理后再恢复。不得绕过验证或通过非公开接口继续。

本轮当前正式库有 40 个 creator 实体、18 条 notes、128 条 records 和 18 个 batches；这些实体数包含历史和采集引用，不等于已核实的不同创作者数。本轮实采目标尚未达成，详见 [V1.4 验收报告](V1.4_ACCEPTANCE_REPORT.zh-CN.md)。

## 停止程序

在启动服务的 PowerShell 窗口按 `Ctrl+C`。离线演示模式为只读；实时数据库路径为 `instance/creatorscope_unified.sqlite3`，不要将实时库覆盖到现有演示副本。
