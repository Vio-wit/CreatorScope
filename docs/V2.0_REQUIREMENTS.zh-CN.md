# CreatorScope V2.0 产品需求与执行基线

日期：2026-11-23。项目保持本地单机定位；以真实采集和字段证据为基础，逐步建设达人库、数据分析、自然语言筛选和合作建议。复用现有实现和历史资产，不推倒重写。

## 本阶段范围

- S1：只读审计现有代码、数据库结构和本地 redbookdate 历史资产，记录来源、字段、身份、缺失和导入风险；不访问远程服务器资产。
- S2：独立浏览器、人工登录和筛选；读取当前结果。安全验证由用户按平台流程处理，不绕过。
- S3：采集五位达人，检查列表、详情、概览、画像、笔记及可访问的公开正文、话题和评论；显示真实任务状态并保存证据。
- S4：按真实批次输出字段质量、解析情况和可用性清单；未实际验证不得承诺可用。S4 完成前不为图表效果扩充分析功能。
- S5–S9：后续分别实施历史资产导入、稳定字段驱动的看板、自然语言筛选、达人对比和笔记评论扩展，不属于本阶段开发范围。

## 采集与验收

五位真实达人任务是课堂演示与字段验证的共同样本。成功率按目标的唯一达人计算，目标 5 人至少 4 人成功（≥70%）。单人成功要求身份可识别且准确关联、本批保存、至少两个可用核心指标，保留原值、来源、时间；重复不重复计数，缺失为 NULL。固定任务分母；结果不足、中止或未尝试不得缩小分母。

针对适用的五人字段：5/5 或 4/5 为小样本稳定，3/5 为部分可用，低于 3/5 不作为核心依据；未测试或样本不足须单独标记。笔记和评论按实际对象数分别统计，不能把 3/3 写为 5/5。字段报告区分页面空值、无法访问、读取失败、解析失败及未测试，记录来源、原值、单位和周期。五人结论不证明长期稳定。

不再要求累计 30 人、三轮、七天监控或长期调度。笔记和评论不可用不阻断达人基础功能。不同来源与周期不混为一谈；无 API Key 或 Agent 时基础采集、数据管理和统计仍可使用。

## 数据与安全

保留原有数据库、未跟踪资料和旧批次。旧批次 39ca… 缺乏稳定身份断点，不续跑；新建批次验证。生产数据库和原始文件不因审计而获得写入或导入授权。业务数据库不得保存密码、Cookie 或 Session。启动服务可能初始化或迁移数据库，须先核查配置与备份；测试使用隔离库。

## 最终产品方向

三个主入口：达人库、数据分析、智能采集。后续 AI 自然语言生成可调整的筛选条件并查询本地达人库，支持横向对比及基于真实数据的建议。字段不足的图表展示覆盖率及原因，不生成虚假数据。
