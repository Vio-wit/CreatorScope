# CreatorScope V1 课堂演示 SOP

建议用时 5–10 分钟。演示读取本机统一 SQLite 数据库，服务只绑定 `127.0.0.1`。

## 1. 启动软件（约 1 分钟）

在 PowerShell 进入项目目录并启动：

```powershell
cd K:\work\CreatorScope
.\run.ps1
```

启动脚本会检查项目虚拟环境和 Python 3.11 版本。已有数据库会先以只读方式检查完整性和外键；Flask 应用随后幂等初始化必要结构。浏览器打开 `http://127.0.0.1:8765`。结束时回到 PowerShell 窗口按 `Ctrl+C`。

## 2. 展示真实历史样本（约 1 分钟）

打开“数据看板”，介绍创作者、笔记、评论和批次总数，并切换顶部批次筛选。2026-11-21 验收时，统一库包含 16 位创作者、16 篇笔记、10 个批次、468 条指标值和 33 条评论快照；具体数字会随本机数据变化。这里展示的是匿名历史样本，不应称为本次现场刚采集的数据。

## 3. 展示采集工作台（约 1 分钟）

进入“采集任务”，查看任务状态和已有批次，再介绍页面中的创作者、笔记与评论数量上限。若现场确实要演示可见页面采集，使用独立浏览器窗口，由操作员手动登录并手动打开目标页面；遇到验证码、登录门槛或页面结构不匹配时停止并保留任务状态。不要录入或复制账号凭据，也不要把历史导入批次说成自动采集成功。

本轮已有的人工可见页面研究记录显示：蒲公英查看过 5 位创作者、9 篇笔记详情和 45 条精选评论摘录；小红书公开页 6 篇笔记均能打开，但只保存 1 条评论样本，未完成评论区批量采集。应用内自动采集任务的实时端到端结果仍需在授权登录环境复验。

## 4. 展示统计与评论分析（约 2–3 分钟）

返回“统计分析”，展示创作者粉丝/报价分布、笔记互动、数据来源和时间趋势等图表。切换一个批次，说明跨批次比较只在来源和统计口径可比时展示。

打开“评论分析”，选择 `xiaohongshu` 批次并输入关键词（例如“链接”），点击“筛选”。验收时该组合返回 6 条记录；页面会同步更新词云和图表。强调评论样本是页面实际可见的小样本，`10+` 等非精确值不会被伪装成精确计数，也不能代表全部评论。

## 5. 展示 AI 范围预览（约 1–2 分钟）

打开“AI 分析”，选“评论主题提取”，选择一个有评论的批次和笔记，点击“生成脱敏预览”。预览只展示计数、长度/点赞分布和高频词，不包含评论原文或评论者身份。

本机目前没有配置模型 API Key。可以展示“未配置密钥”和本地预览仍可用的状态；连接测试会返回 `not_configured`，不会请求外部模型。若之后由负责人员配置密钥，只有在检查预览并明确确认数据外发后，才运行模型分析；该操作会把预览内容发送给所选服务商。

## 6. 展示导出（约 1 分钟）

在主看板点击“导出 JSON”或“导出 CSV”；在评论分析页点击“导出 JSONL”或“导出 CSV”。导出文件由浏览器下载。验收时四个接口均返回 HTTP 200。

## 演示边界

- 本机默认数据库为 `instance\creatorscope_unified.sqlite3`；验证时使用过的 SQLite 副本保存在 `_preview\`，不需要纳入 Git。
- 公开页可见数据、蒲公英指标和小红书指标应按来源及时间区分。
- 真实现场采集、评论批量采集和真实模型 API 均未在本轮最终验收中成功完成；请按上文边界演示，不承诺自动采集或模型输出。
