# CreatorScope V1.1 课堂演示 SOP

建议用时 5–10 分钟。演示范围以 2026-11-21 本轮实际验收为准：统计、评论分析、AI 本地预览和导出可演示；完整的蒲公英到小红书自动采集尚未通过现场验收。

## 1. 启动软件

在 PowerShell 中执行：

```powershell
cd K:\work\CreatorScope
.\run.ps1
```

默认打开 `http://127.0.0.1:8765`。结束时回到服务窗口按 `Ctrl+C`。正式数据库为 `instance\creatorscope_unified.sqlite3`。

## 2. 介绍当前数据范围

本轮验收结束时，正式库包含 17 位创作者、16 篇笔记、12 个批次、92 条记录、472 条指标值和 33 条评论快照。A 阶段基线是 16 位创作者、16 篇笔记、10 个批次、91 条记录和 468 条指标值；本轮只新增 1 条蒲公英当前可见列表样本及 4 条指标值。

新增列表记录的四个字段均非空且解析成功：粉丝数、阅读中位数（日常）、互动中位数（日常）、全部报价。它没有产生新的创作者实体、笔记或评论，不能作为完整创作者采集闭环展示。

## 3. 展示采集工作台

从工作台使用“打开蒲公英浏览器”，在可见窗口正常登录并手动停留在博主广场。可用“采集当前页面”展示本轮真实完成的列表样本采集；页面和批次会记录来源、时间及指标。

本轮另从 CreatorScope 页面创建了最小任务（1 位创作者、每人 2 篇笔记、每篇最多 10 条评论）。列表行点击被页面中央弹层遮挡，任务停止时创作者详情、笔记和评论均为 0，记录了 4 个点击失败点。因此不要把该任务讲成自动采集成功。当前代码会在目标被弹层遮挡时暂停并保留断点；这一新暂停提示只通过合成测试验证，尚未在真实页面复验。

遇到登录要求、验证码或访问限制时停止相关采集，不绕过验证，也不录入或复制账号凭据。若弹层没有明确可见的正常关闭控件，先由操作员在平台界面确认处理方式。

## 4. 展示分析与评论

主看板和统计分析展示当前本地统一库中的历史/实测样本；来源分析按记录级来源区分。主看板实际渲染 18 个 ECharts 画布。

评论分析页展示 33 条已保存评论快照和 7 个图表画布。样本来自历史人工可见页面记录，不代表本轮应用自动采集的评论总量。`10+` 等非精确显示值不会转换成精确整数。

## 5. 展示 AI 本地预览

打开“AI 分析”，选择“评论主题提取”、已有评论批次和笔记，点击“生成脱敏预览”。本轮从页面成功生成本地预览；执行模型的按钮仍保持禁用，因为本机没有配置模型 API Key。连接测试返回 `not_configured`，没有真实模型请求或第三方数据发送。

如未来配置服务商密钥，必须先检查预览，并由负责人明确确认数据外发后才运行模型分析。

## 6. 展示数据导出

主工作台现在提供：原始记录 JSON/CSV、标准化指标 JSON/CSV、统计结果 JSON。笔记页另有 CSV；评论页提供 CSV 和 JSONL。导出会保留记录来源、批次、采集时间；指标导出还包含原始值、标准化值、单位、统计周期、解析状态和缺失状态。

本轮接口验收返回 HTTP 200：原始记录 JSON/CSV 各 92 行，标准化指标 JSON/CSV 各 472 行，笔记 CSV 16 行，评论 CSV/JSONL 各 33 行。

## 演示边界

- 历史导入和人工研究样本必须标为历史/人工来源，不能描述成现场自动采集。
- 本轮应用内可见页面采集仅完成一条列表样本；创作者详情、笔记正文和评论自动采集仍待现场验收。
- AI 仅完成本地预览与未配置状态验证，未连接真实模型。
- 若课堂演示要求完整自动采集闭环，应先在正常授权会话中处理页面弹层，再从创建任务开始复验。
