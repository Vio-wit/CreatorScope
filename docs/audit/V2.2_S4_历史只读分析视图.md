# V2.2 S4：历史只读分析视图

核验日期：2026-11-23。分析使用 S3 隔离证据库 `_preview/v22_s3_history_final_20261123.sqlite3`。本阶段只读查询该库，没有写入正式达人库、隔离证据库或历史原始资产。

## 实现范围

- 新增 `creatorscope/history_analytics.py`，用 SQLite `mode=ro` 和 `PRAGMA query_only=ON` 读取历史证据，并检查 CreatorScope 隔离库标记。未创建视图、表或迁移。
- 增加 `/api/history-analysis/sources`、`/api/history-analysis` 和 `/api/history-analysis/note-samples` 三个只读接口。分析数据以来源文件名、SHA-256、来源行号和原始采集时间（若有）保留追溯信息；页面只显示数据集和样本数。
- 分析仅接受解析成功、单位为计数且非负的数值；0 保留为有效值。每个来源单独计算，不跨数据集拼接样本。表格空值保持为空。
- 默认历史库路径为 `_preview/v22_s3_history_final_20261123.sqlite3`，也可用 `CREATORSCOPE_HISTORY_DB` 指定。文件不存在或标记不符时，接口返回不可用状态，不回退查询正式达人库。
- 新增首页历史分析区：来源选择、粉丝规模分布、日常阅读与互动散点、字段覆盖、逐行横向比较和三篇课堂笔记样本。界面不展示身份核验状态或账号身份信息。
- 用共享侧栏把主要入口收拢为达人库、数据分析、AI 辅助、采集任务；评论、质量、报告、新闻及其他现有功能放入“更多工具”，保留原页面与链接。
