## 1. 本轮交付

- 加入统一字段观察记录，覆盖 `captured`、`not_displayed`、`not_loaded`、`access_denied`、`parse_failed`、`not_attempted`、`not_applicable` 七种状态。保留原始页面显示字符串；标准化值单独记录；缺失值不填成 0。

- 增加每批质量接口与覆盖率、解析率、失败和去重报告生成器。
- 增加 `run.ps1 -Mode Demo`。该模式使用真实历史数据库副本，阻止写操作，不启动采集浏览器，也不调用外部智能体或模型。
- Live 启动检测到已有数据库 schema 低于当前版本时，会先在 `_backup/` 创建 SQLite Online Backup 并校验；备份失败时阻止初始化和迁移。
