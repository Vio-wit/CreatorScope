1. 启动 CreatorScope，打开可见蒲公英浏览器；由操作员在平台正常界面确认弹层状态和授权登录。登录/验证码/访问限制出现时停止，不绕过。

3. 如需真实 AI，先在本机进程配置密钥/模型；检查包含完整原始字段的本机预览并确认外发范围后再调用。
4. `_backup\`、`_preview\`、Playwright 快照、既有 `research\` 和 `vendor_sources\` 均为保留的本地资料；不要用 `git add .`，也不要删除或覆盖这些内容。
