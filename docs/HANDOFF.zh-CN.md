1. 在有授权的登录会话中，对应用内可见采集从创建任务到打开页面、解析字段/评论、暂停恢复、失败重试和重启断点续跑做一次完整现场验收；不绕过登录或平台验证。
2. 如果要验收模型结果，由负责人先在本机进程设置服务商 Key 和模型，再审查预览与外发范围；不要将凭据写入仓库或报告。
3. 当前评论情绪属于小样本探索；历史指标缺少精确 note ID 或创作者关联的条目仍应按审计报告保留为未关联，不要通过昵称猜测合并。
4. 运行后检查 `git status --short`。`_backup/`、`_preview/`、浏览器快照、原始研究目录、验证数据库和 `vendor_sources/` 均为本地资料，不要使用 `git add .`。
