# CreatorScope V1.3 课堂演示指南

## 离线演示

在 Windows PowerShell 中进入项目目录，然后运行：

```powershell
cd K:\work\CreatorScope
.\run.ps1 -Mode Demo
```

启动后访问 `http://127.0.0.1:8765`。若该端口已被现有 CreatorScope 服务占用，可以在新窗口临时使用其他端口：

```powershell
$env:CREATORSCOPE_PORT = '8766'
.\run.ps1 -Mode Demo
```

演示模式检查本地数据完整性，打开后可查看看板、创作者、笔记、评论、统计分析和导出。演示数据是此前真实采集保存的本地历史数据副本，不是模拟账号或虚构样本。此模式不要求登录、外网、Codex、Agent、MCP 或模型 API Key。筛选、图表和导出读取副本内的数据；创建实时采集、导入或其他写入请求会被拒绝。

建议演示顺序：

1. 打开看板，介绍数据总量和字段覆盖概况。
2. 查看创作者与笔记列表，展示真实历史原始字段和来源。
3. 进入分析页，展示创作者、笔记、评论统计和词云；图表显示实际样本量，样本不足时不会生成结论。
4. 使用页面筛选和导出，展示本地数据处理流程。
5. 说明离线模式展示历史数据，页面不会因此声称本轮完成了实时平台采集。

演示截图：[主看板](../output/playwright/v13-offline-dashboard.png)、[统计分析](../output/playwright/v13-offline-analytics.png)。

停止演示时，在启动服务的 PowerShell 窗口按 `Ctrl+C`。

## 实时采集模式

完成现场登录和网络条件确认后，在项目目录运行：

```powershell
.\run.ps1
```

访问 `http://127.0.0.1:8765`，在采集工作台中打开独立可见浏览器，在平台页面正常登录后创建小样本任务。采集受登录状态、页面可见范围和平台访问权限约束；遇到验证码、权限拒绝或安全验证时，应按页面提示人工处理或停止任务。不要关闭安全提示或强行点击遮罩。

任务页面提供进度、失败原因、暂停/恢复/停止和失败笔记重试。单篇普通加载或解析失败不会自动终止整批，但实时稳定性仍须以平台上的三轮实际采集记录验收。字段原始显示值与来源写入本地 SQLite；评论不采集评论者账号、头像和主页信息。

## 数据位置与运行模式

- 离线演示库：`data/demo/creatorscope_demo.sqlite3`，只读真实历史副本。
- 默认实时库：`instance/creatorscope_unified.sqlite3`。
- 浏览器使用独立持久配置；需要平台登录时由用户在可见浏览器中正常操作。
- 默认地址：`http://127.0.0.1:8765`。可用 `CREATORSCOPE_PORT` 指定其他本地端口。
