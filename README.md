# CreatorScope

面向《数据采集与处理综合实训》的本地独立课程原型。当前首个切片包含：匿名蒲公英真实样本导入、SQLite 批次存储、字段覆盖与数值清洗、交互看板，以及一个使用隔离用户目录的可见 Playwright 浏览器入口。

## 环境与运行

要求 Windows、Python 3.11 和可访问 PyPI 的网络。项目依赖安装在本目录的 `.venv`，不修改全局 Python。

```powershell
cd K:\work\CreatorScope
.\setup.ps1
.\run.ps1
```

打开 <http://127.0.0.1:8765>。本地服务只绑定回环地址，不提供公网服务。需要停止时，在运行窗口按 `Ctrl+C`。

## 第一个端到端切片

1. 点击“导入基线样本”。应用把保留的匿名真实样本读入 SQLite，并建立一个历史批次。
2. 查看字段原值、有效字段数、解析成功的数值、分类图表及样本可用性提示。
3. 可选：点击“打开蒲公英浏览器”，在新建的隔离配置窗口中正常登录并手动进入页面。应用不会读取旧浏览器配置、调用页面私有接口或保存整页文本。
4. 确认页面位于 `pgy.xiaohongshu.com` 后点击“采集当前页面”。目前只尝试提取可见 DOM 中已支持的列表指标或详情标签；页面结构不匹配时任务会失败并显示原因，不会猜值。

每次导入/采集都写入新批次。SQLite 文件位于 `instance\creatorscope.sqlite3`；浏览器独立用户目录位于 `%LOCALAPPDATA%\CreatorScope\pgy_browser_profile`。不要把账号凭据复制到项目文件。

## 当前切片边界

- 列表行解析面向页面可访问性树中的表格行；详情解析使用页面可见标签和值，实际页面结构仍需在用户正常登录后逐页验证。
- 页面采集暂不处理筛选条件、分页遍历、批量详情跳转或笔记列表循环；本切片只采当前可见页的少量字段。
- 原值保留在记录 JSON 中；可识别的计数、比例、报价另存为规范化指标。日期/分类等文本不再被误解析为数字，范围报价标记为未解析。
- 只有存在可用标题/正文时才生成词频；没有真实对应字段时看板显示不可用原因。
- ECharts 6.1.0 的本地发行文件及许可证位于 `static\vendor`。本地页面无需加载远程脚本或字体。
