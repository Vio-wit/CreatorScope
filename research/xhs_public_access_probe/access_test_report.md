# 小红书公开笔记多标签访问与评论采集验证

**执行日期：** 2026-11-20（Asia/Shanghai）  
**范围：** 2 位创作者，每位 3 篇笔记；仅使用蒲公英页面“复制小红书笔记链接”取得的链接。  
**结果：** 6 篇不同笔记均成功打开；未登录小红书，未调用非公开接口。

## 环境与操作

- 使用 CreatorScope 现有 `.venv`、Playwright 可见 Chromium 和原有独立蒲公英浏览器配置；未安装/升级依赖，未读写账号密码、Cookie 或 Session。
- 实测运行时为 Python 3.11.9、Playwright 1.60.0；使用项目现有 `PgyVisibleBrowser` 启动程序。
- 登录蒲公英后，从博主详情的笔记卡片执行普通可见点击，再点击“复制小红书笔记链接”。链接只在本次浏览器进程内用于打开页面。复制结果含 `xsec_source`、`xsec_token` 查询参数；实验文件仅保留公开笔记路径及 note_id，不保留查询参数值。
- 按顺序验证当前标签和新标签访问。六个不同 note_id 都在新标签成功加载；首条还分别以当前标签和新标签重复访问一次。页面标题与目标笔记标题逐一匹配。
- 六个唯一页面首次访问均出现“手机号登录”弹窗；通过页面明确可见的 X 关闭。关闭后正文、话题、互动量与评论区仍可见，未触发短信/验证码流程。另一次首条新标签重复访问没有再次显示弹窗。
- 连续保持多个标签后，关闭一个笔记标签，剩余标签的 URL 路径和页面标题未改变。没有观察到串页。访问按顺序执行，未并行发起网络请求。
- 蒲公英内部通知弹层通过“暂时忽略”正常关闭；它不是小红书手机号登录弹窗。

## 结果与数据质量

- **唯一笔记：** 6 篇；两位创作者各 3 篇。**访问成功：** 6/6；标题匹配：6/6；新标签打开：6/6。另有首篇当前标签访问及一次新标签重复快照。
- **字段覆盖：** 标题、话题标签、显示时间、点赞、收藏、评论总数均为 6/6；可见正文段落为 3/6；分享数量为 0/6（页面没有数值）；视频类型可确认 5/6，另 1 篇媒体区未加载而保留 null。
- **同笔记快照变化：** 首篇约 6 分钟内点赞从 6,064 变为 6,105，收藏从 578 变为 580，评论仍为 580。说明多批次数据应保留 capture_time，不能覆盖历史指标。
- **评论区：** 六页都显示评论区及总评论数。只对首篇执行正常滚动，随后看到更多评论行。保存 1 条评论样本；未遍历评论、未展开回复、未发现明确的评论分页/排序切换控件。可见“精选评论”“置顶评论”“展开3条回复”等页面提示。
- **评论样本：** 首篇一条置顶评论文本、显示时间“2天前”、区域“北京”、点赞“10+”、回复“10+”。未保存评论者昵称、账号 ID、头像或主页链接。exact-text 定位器本轮未命中该评论，故评论内容虽可见且整页 DOM 文本包含锚点，本轮不认定稳定评论 DOM 解析器已完成。
- **媒体：** 可见竖屏媒体画面/播放器区域；未下载图片或视频。XHS 页没有稳定读到图片总数、视频时长或分享数值。部分媒体显示加载转圈或黑屏，播放完整性未验证。
- **跨源差异：** 蒲公英内部详情/卡片的阅读、曝光、互动等参考值保存在 `pgy_reference`，没有覆盖 XHS 页快照。两边统计口径与时间不同，不能直接当成同一指标。

## 失败与限制

1. 首次点击第三篇蒲公英卡片时，前一条内部详情面板未关闭，点击超时且剪贴板仍是上一条链接。该结果被识别为重复并排除；关闭面板后重新点击、复制，取得正确的第三个不同 note_id。
2. 评论 exact-text Playwright 定位未命中；页面全文 DOM 中有评论文字，但全文也包含推荐内容。尚需按笔记详情容器建立稳定、最小化身份字段的评论解析器。
3. 一篇笔记媒体区域黑屏/加载中；不据此推断其类型。

## 对 CreatorScope 的建议

- P0 可加入：从已授权的蒲公英复制链接进入公开笔记、单页当前/新标签采集、标题/正文/标签/发布时间与互动快照、每次采集批次、null 缺失语义。
- 评论先作为小样本实验功能，必须按笔记详情容器定位；只保留评论文本、显示时间、点赞/回复和置顶状态，不采评论者身份。
- 指标模型按 `source + note_id + capture_time + raw_value + normalized_value + unit` 保存；蒲公英与小红书分开记录，保留短格式和近似转换标记。
- 不建议当前把评论批量采集、图片/视频下载或分享数推断纳入 P0。本轮未验证大规模、长时间稳定性或平台规则对自动化访问的授权范围。
